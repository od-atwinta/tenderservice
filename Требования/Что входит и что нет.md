# Что входит в сервис и что нет

Часть общего документа "Карта процесса и требования".

Статус документа: рабочая версия. Дополняется по ходу проектирования.

---

## Входит

- Весь цикл тендера от выгрузки до закрытия сделки.
- Копилка документов с разделами внутри (учредительные, архив поданных предложений и другие).
- Чат внутри каждого тендера для обсуждения сотрудниками (замена Telegram-темы). Не отдельная вкладка — постоянная плавающая иконка в углу экрана, открывает панель справа. Иконка меняет вид в зависимости от состояния: пусто / есть непрочитанные / всё прочитано.
- Вкладка "События" для истории коммуникации после подачи.
- Вкладка "Логи" хранит системную историю тендера: все изменения, кроме
  сообщений чата - смену статуса, загрузку документов, назначение
  ответственных и другие действия.
- Чек-лист документов с редактированием: у каждого пункта есть срок и ответственный (выбирается из участников тендера), пункты можно добавлять (быстро — через "+", или в режиме редактирования — через "✎") и удалять.
- Постоянная панель со списком тендеров справа от карточки конкретного тендера (видна всегда, не привязана к вкладке). Её верхняя граница выровнена со строкой вкладок карточки. Каждая строка списка: название (ссылка на карточку), статус, цветовой индикатор нового сообщения в чате этого тендера. В список входят все тендеры, которые хотя бы один раз были взяты в работу, включая перешедшие затем в Архив. Тендеры, отклонённые до взятия в работу, не входят. Ограничения списка задают права пользователя, фильтры исходной страницы, выпадающий фильтр направления и чекбокс "Только мои". Сортировка по умолчанию — по дате последней активности, сверху новые. Открытый тендер не меняет позицию и выделяется только розовой заливкой. Ограничения количества строк нет; длинный список прокручивается. Чат открывается поверх этой панели. Текущий этап и нейтральная кнопка "Изменить статус" находятся в самостоятельной карточке внутренней правой колонки основного контента. Плашка срока подачи находится в правой части шапки на одной горизонтали со строкой заказчика и НМЦ.
- Последней активностью считаются сохранённые изменения полей, статуса,
  направлений, ответственных, документов, комментариев и новые сообщения.
  Обычный просмотр карточки активностью не считается. Для старых данных без
  отдельной даты активности используется последнее событие, затем дата
  создания.
- Правило оформления "новое / просмотрено" (применять на любых будущих списках тендеров, не только в этой панели): если после последнего посещения карточки не было новых событий, название показывается приглушённым серым обычной насыщенности; если появились новые события — название чёрное и жирное. Это отдельный признак от точки-индикатора чата (у чата своя логика: есть непрочитанные / всё прочитано / пусто), оба признака показываются одновременно и независимо.
- Сводная таблица поданных заявок с фильтрами и выгрузкой.
- Индикатор риска от ИИ в карточке тендера (например нужна консультация юриста).
- Поля площадки в карточке тендера редактируются через иконку-карандаш:
  тип подачи ("На площадке" или "На почту"), ссылка на саму закупку на
  площадке, условие подачи в виде суммы в рублях и комментарий. Если сумма
  не заполнена, сохраняется `0 ₽`. Ссылка может прийти автоматически при
  создании карточки после успешного парсинга или быть добавлена вручную; при
  типе "На площадке" она открывается по тексту "На площадке ↗". Ссылка на
  источник тендера хранится отдельно и зависит от интеграции с агрегатором.
- Интеграция с Jira для постановки задач на оценку специалистам (в перспективе).
- Финансовая статистика по оплате площадок, вносится вручную, структура раздела будет продумана позже.
- Уведомления всем участникам тендера при смене статуса.
- Добавление в избранное доступно на любом существующем этапе тендера:
  в сводной таблице, карточных списках и самой карточке. Признак один и
  синхронизируется между экранами.
- Редактирование срока подачи в карточке тендера (для тендеров "В работе"): рядом с датой окончания сбора — иконка-карандашик. Клик переключает поле в режим редактирования (числовой ввод даты и времени, тот же тип поля, что в форме "Добавить тендер"), рядом появляется иконка "сохранить". После сохранения новое значение обновляется везде: в самой карточке, в колонке "Окончание сбора" сводной таблицы (с пересчётом цветовой подсветки срочности), фиксируется в "Истории изменений" тендера, и все участники тендера получают уведомление. Право редактировать — см. `Роли и участники.md`.
- Редактируемый в админ-панели список направлений.
- Меню портала (левый сайдбар, на каждой странице сервиса): подпись "Тендеры Атвинта" сверху, кнопка сворачивания рядом с подписью, дальше пункты — Дашборд; Тендеры (с подпунктами Сводная таблица / Новые / Ожидают решения / В работе / Архив, у Новых, Ожидают решения и В работе — счётчик количества); Заявки; Избранное; Календарь (счётчик задач на сегодня); Копилка; Пользователи; Профиль; Платежи; Настройки (последний пункт списка, доступен только суперадмину). У каждого пункта верхнего уровня — своя иконка.
- **Взаимосвязи между уже построенными экранами.** При создании новой страницы-макета сразу проставлять рабочие ссылки на другие уже построенные страницы там, где это соответствует функционалу (не оставлять "#"-заглушки для того, что уже существует). Для ещё не спроектированных экранов ссылка остаётся "#" до тех пор, пока экран не появится.
- Меню сворачивается до узкой полосы из одних иконок (подписи, счётчики, дата/время и текст в блоке пользователя скрываются, остаются только иконки с подсказкой при наведении). При сворачивании рабочая область автоматически расширяется на освободившееся место.
- Блок меню зафиксирован (не прокручивается вместе со страницей) — при прокрутке длинной таблицы или контента меню всегда остаётся на месте, двигается только рабочая область справа.
- Пункт меню "Тендеры" открывает сводную таблицу со всеми тендерами любого статуса сразу. Столбцы, после пересмотра (короче исходного набора из Тендеры.xlsx): избранное (звезда), Ответственный, Название, Статус (раздел жизненного цикла — Новый/В работе/Заявки/Архив, цветная метка), Заказчик, НМЦ, Дата публикации, Источник (ссылка на Тендерплан), Отчёт (кнопка "Отчёт ИИ" открывает отчёт в модальном окне внутри сервиса — это не ссылка на внешний документ, а контент, который хранит сам сервис; см. компонент "Отчёт ИИ" в `Дизайн-система.md`), Дата окончания сбора, Отдел, Решение, Причина отказа, Дата создания строки. Ответственный/Отдел/Решение/Причина отказа — редактируются прямо в таблице (выпадающий список), доступно только администратору. Клик по названию открывает карточку тендера. В таблице: поиск (в строке фильтров, прижат к правому краю, рядом кнопка "Выгрузить в Excel"), фильтры (статус-раздел, дедлайн до, источник/площадка, менеджер, направление, только избранные), сортировка по названию и по дате окончания подачи, пагинация с выбором количества строк (10/20/50/100/все, по умолчанию 20), количество отображаемых строк показано над таблицей.
- Выгрузка в Excel выгружает то, что видно с учётом текущих фильтров и сортировки (не только текущую страницу пагинации). Технически это файл `.csv` (открывается в Excel так же, как обычная таблица) — настоящий бинарный `.xlsx` без сторонних библиотек в этом типе макета не собрать.
- Дата окончания сбора подсвечивается по срочности: сегодня (и просроченные) — розовым, завтра или послезавтра — жёлтым, больше двух дней — серым (нейтрально, без подсветки).
- Шапка страницы — сквозной элемент в один ряд: заголовок слева, справа единый кластер (колокольчик, календарь, тонкий разделитель, "Добавить тендер"). Между страницами меняются только название и количество показанных строк. Кнопка "Обновить" есть только на странице "Новые".
- Нулевой счётчик в левом меню не показывается: если в разделе "Новые"
  нет тендеров, цветной бейдж с `0` скрыт.
- Быстрые чекбоксы: на странице "В работе" — "Только мои"; на странице
  "Ожидают решения" — "Только мои" и "Избранные". "Только мои" сравнивает
  ответственного по тендеру с текущим пользователем.
- Колокольчик и календарь — монохромные значки (не цветные эмодзи), в едином нейтральном стиле с остальными иконками. Колокольчик открывает всплывающее окно с новыми событиями: системные уведомления, новые сообщения в чатах тендеров пользователя, приближающийся срок подачи по тендерам из "В работе", с индикатором наличия нового события. Календарь рядом (левее кнопок) открывает всплывающее окно со списком задач на сегодня.
- В карточке тендера блок "Ответственные" показывает менеджера и участников
  выбранных направлений. Карандаш открывает модальное редактирование состава;
  сохранение обновляет общие данные карточки и историю событий. Конкретные
  права ролей на это действие согласовываются отдельно.
- Карточка поддерживает последовательные многоэтапные тендеры. По умолчанию
  создаётся одна секция. После включения признака "Многоэтапный" менеджер
  может добавить следующую секцию только после положительного решения
  "Допущены" по предыдущей. Вкладка "Этапы и заявки" хранит заявки, сроки,
  готовность и связи с документами по каждой секции. Завершённая секция
  сохраняется неизменяемым снимком.
- В режиме редактирования секции доступны: название этапа, общий дедлайн,
  документы секции и документы на подачу. Название выбирается в фиксированном
  порядке НДА, ПКО, Основной, Этап 2, Этап 3, Переторжка, RFI; "Итог" в
  список не входит. Сохранённый дедлайн синхронизируется с плашкой "Срок
  подачи" в шапке.
- Документ в секции можно добавить, скачать кликом по плашке и убрать из
  секции крестиком. Удаление из секции снимает связь, но не удаляет запись
  из общей библиотеки. Для документов на подачу дополнительно доступны
  скачивание одним ZIP-архивом и множественный выбор файлов из папок
  подраздела "Документы" Копилки.
- Любой загружаемый в секцию файл сначала проверяется по названию в общей
  библиотеке. Точные и частичные совпадения показываются в предупреждении
  списком. Точное совпадение повторно использует существующий файл, поэтому
  одна и та же запись не хранится дважды.
- Добавление, удаление и выбор документов не сбрасывают ещё не сохранённые
  значения названия этапа, дедлайна и полей заявок в открытом редакторе.
- Общие документы тендера хранятся отдельно и могут подключаться к нескольким
  заявкам без копирования файла. В раскрытой части превью страницы
  "В работе" прикреплённые документы располагаются перед последним событием;
  полный список событий там не дублируется. Во вкладке "Обзор" отдельной
  страницы тендера история событий не показывается, а блок прикреплённых
  документов всегда остаётся раскрытым.
- Во вкладке "Обзор" отдельной страницы тендера описание закупки и
  комментарий менеджера редактируются через карандаш. Отчёт и рекомендация
  ИИ объединены в одну сворачиваемую секцию: ссылка открывает полный отчёт
  в модальном окне, а кнопка генерации остаётся доступной. Состояние
  сворачиваемых секций сохраняется отдельно для каждого тендера.
- Чекбокс "Многоэтапный" на отдельной странице тендера находится во вкладке
  "Этапы и заявки". Вкладка "Оценка и оплата" не используется.
- Во вкладке "Этапы и заявки" нет повторного внутреннего заголовка и
  поясняющего текста. Кнопка "Добавить этап" начинается от левого края
  своей строки, выбор названия этапа расположен рядом.
- Направления тендера показываются слева отдельной группой разноцветных
  пастельных тегов; технические теги закупки находятся справа на уровне
  строки предупреждения о проверке у юристов. Направления поддерживают множественный выбор. При
  удалении направления система перечисляет в подтверждающем окне всех
  участников этого направления; по кнопке "Удалить" направление и эти
  участники снимаются, а крестик отменяет изменение и закрывает оба окна.
  Результат сохраняется в общей псевдосинхронизации и истории событий.
- Открытый множественный список направлений или участников не перекрывает
  рабочее поле и нижние кнопки модального окна: он раздвигает содержимое,
  имеет ограниченную высоту и собственную прокрутку. Между чекбоксом и
  текстом сохраняется `8px`.
- Страница "Настройки" начинается с подраздела "Справочники". В первой
  версии редактируются направления, причины отказа, решения об участии,
  секции тендера, статусы заявки, валюты, типы закупки и основания. Этапы
  процесса фиксированы и не редактируются. Изменения сохраняются локально и
  используются готовыми формами сервиса. Сотрудники, менеджеры, площадки и
  промпты ИИ в этот первый подраздел не включаются.
- Кнопка "Выгрузить в Excel" — компактная иконка (не текстовая кнопка), стоит в строке фильтров сразу после поля поиска, а не рядом с "Добавить тендер" — это вспомогательное действие над текущим видом таблицы, не основное действие страницы.
- Кнопка "Добавить тендер" в сквозной шапке выполняет создание тендера с
  любой страницы сервиса. Форма содержит название, заказчика, НМЦ, ссылку
  на источник, дату и время подачи, а также выбор раздела. По умолчанию
  выбран раздел "Новые"; можно выбрать "Ожидают решения", и тогда карточка
  сразу создаётся с решением "На рассмотрении" и отображается в этом разделе.
  Дата создания строки проставляется автоматически, ответственный при
  создании не назначается. После сохранения уведомление называет выбранный
  раздел. Отдельной ветки для вручную добавленных тендеров нет.
- Все выпадающие списки (в фильтрах, в таблице, в пагинации) — полностью свой стилизованный виджет (кнопка + список поверх интерфейса), а не нативный `<select>` браузера. Открытый список нативного `<select>` рисует сама операционная система и стилизовать его через CSS невозможно в принципе — поэтому пришлось заменить весь компонент, а не только его "закрытый" вид.
- В меню портала, после пунктов меню и перед блоком пользователя (с разделителями с обеих сторон) — блок с текущей датой и временем. Время идёт вживую.
- Группировка тендера на укрупнённые разделы "Новые / В работе / Заявки / Архив" — см. новый блок в `Статусы и справочники.md`.

## Правила оформления (кросс-экранные, применять на всех будущих экранах)

- Без хлебных крошек — в этом сервисе они не нужны нигде.
- Карточка тендера не является исключением: над рабочей карточкой хлебные
  крошки не показываются.
- Без описания/подзаголовка под заголовком страницы — не нужно вообще, ни на одном экране.
- Только монохромные иконки (свой SVG в цвет интерфейса), без цветных эмодзи вроде 🔔/📅/🔍 — эмодзи всегда рисуются в своих ярких цветах независимо от CSS и выбиваются из стиля.
- Все `<select>` (выпадающие списки) стилизованы под общий вид (единая стрелка, скругления), не нативный вид браузера.
- В шапке страницы — воздух между блоками: не лепить заголовок/фильтры/таблицу вплотную друг к другу.
- В меню портала (общее для всех экранов) — блок текущей даты и времени после пунктов меню, перед блоком пользователя, с разделителями с обеих сторон.
- Меню портала зафиксировано на экране, сворачивается до иконок, рабочая область смещается и расширяется соответственно.
- Правило "новое / просмотрено" для названий тендеров в списках — см. пункт выше про панель списка тендеров.

## Не входит

- Гранты — исключены из объема сервиса.
- ИИ чат боты (отдельное направление из таблицы) — исключены из объема сервиса.
